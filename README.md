# IPShowTips-Plus（IP 悬浮窗 + IP 切换）

当前版本：v1.2.0

一款轻量级的 Windows 桌面小工具，在屏幕右下角以悬浮球形式实时显示你的**公网 IP、归属地与内网 IP**，并内置**网卡 IP 快速切换**功能。适合需要随时关注 IP 变化、并在多套网络配置间快速切换的用户（远程办公、内网渗透测试、网络调试等场景）。

本项目基于 [achabuhecha/IPShowTips](https://github.com/achabuhecha/IPShowTips)（MIT）的 Python 版本二次开发，在其基础上新增内网 IP 显示与 IP 切换功能。

## 功能特点

**悬浮窗（继承自 IPShowTips）**

- 悬浮球显示：默认以圆形悬浮球常驻桌面，置顶显示，不遮挡正常工作
- 公网 IP 查询：自动获取当前公网 IP 及归属地（运营商/省市）
- 定时刷新：每 10 秒自动刷新一次 IP 信息
- IP 变化提醒：检测到 IP 变更时弹出提醒框，显示原 IP、新 IP 与归属地
- 自由拖动：按住悬浮球拖动即可调整位置
- 单击展开：单击悬浮球展开详情面板，鼠标移开后自动收起
- 智能展开方向：靠近屏幕边缘时面板向内侧展开，避免内容被裁切
- 系统托盘：可最小化到任务栏托盘区，后台继续监控
- 开机自启动：右键菜单 / 托盘菜单可勾选

**新增功能**

- 内网 IP 显示：面板实时显示本机内网 IP（10.\*/192.\* 段，默认路由优先，自动排除 VMware/Hyper-V/WSL 等虚拟网卡）
- IP 快速切换：右键菜单一键打开切换面板
  - 自动获取（DHCP）一键切换
  - 预设方案快速填参（由本地 `ip_presets.json` 配置，默认含办公/家庭/开发三套示例）
  - 自定义静态 IP / 掩码 / 网关 / DNS
  - 查看当前网卡配置
  - 多网卡下拉选择
- 切换成功后悬浮窗内网 IP 立即刷新

## 快速开始（exe 用户）

双击运行 `dist/IPShowTips-Plus.exe` 即可，屏幕右下角出现 IP 悬浮球表示启动成功。

> 若托盘区看不到图标，请点击任务栏右下角 `^` 展开隐藏图标。

## 操作说明

| 操作 | 说明 |
| --- | --- |
| 拖动悬浮球 | 按住左键拖动，调整位置 |
| 单击悬浮球 | 展开 IP 详情面板（公网 IP / 归属地 / 内网 IP） |
| 鼠标移开面板 | 自动收起为悬浮球 |
| 右键悬浮球 | 打开菜单（最小化到托盘 / 切换IP / 开机自启动 / 退出） |
| 双击托盘图标 | 重新显示悬浮球 |
| IP 变化 | 自动弹出提醒，点击「知道了」关闭 |

### IP 切换使用

1. 右键悬浮球 →「切换IP...」
2. 选择网卡（默认选中活动网卡）
3. 切换方式：
   - **DHCP**：点「自动获取 (DHCP)」
   - **预设**：点预设方案按钮自动填参 → 按需修改「IP 末位」后再点一次预设刷新 IP →「应用静态配置」
   - **自定义**：直接填写完整参数 →「应用静态配置」
   - **查看配置**：点「查看当前配置」显示 netsh 输出
4. 应用时会弹出 **UAC 提权确认**（netsh 修改网络配置需要管理员权限），随后出现配置确认框

### 预设配置

预设方案从程序同目录的 `ip_presets.json` 读取（**该文件含内网拓扑，默认不随仓库发布**）。首次使用时复制示例模板并按需修改：

```bash
copy ip_presets.example.json ip_presets.json
```

格式（`dns2` 可省略）：

```json
[
  {
    "name": "办公 192.168.10.x",
    "base": "192.168.10",
    "mask": "255.255.255.0",
    "gateway": "192.168.10.254",
    "dns1": "192.168.10.1",
    "dns2": "223.5.5.5"
  }
]
```

> 配置文件与 exe/脚本同目录（exe 打包版同样生效）；未配置或解析失败时使用内置示例预设。

## 开发与运行

环境要求：Windows 10/11，Python 3.8+

```bash
pip install -r requirements.txt
python ip_widget.py
```

### 打包为 exe

```bash
pip install pyinstaller
build.bat
```

输出：`dist/IPShowTips-Plus.exe`（约 20 MB）。最终用户无需安装 Python，直接运行 exe。

## 常见问题

**Q：切换 IP 时弹出 UAC 窗口正常吗？**
正常。修改网络配置需要管理员权限，脚本会临时提权执行 netsh，完成后自动退出。若取消 UAC，切换不会生效。

**Q：内网 IP 显示 `--`？**
说明当前没有 10.\*/192.\* 段的内网地址（或均为虚拟网卡）。可在 `ip_switcher.py` 的 `_VIRTUAL_NIC_RE` 中调整虚拟网卡过滤规则。

**Q：悬浮球点不动 / 拖不动？**
请用左键按住圆球本身拖动；轻点一下（不拖动）才会展开面板。

**Q：如何彻底退出？**
右键悬浮球 →「退出程序」，或右键托盘图标 →「退出」。
